# Repository Instructions

- Preserve the original 2048 gameplay unless a task explicitly changes it.
- Keep 2048 as the default winning target.
- Use only the supported winning targets: 512, 1024, and 2048.
- Keep the application dependency-free in the browser.
- Run `npm test` after JavaScript, HTML, or styling changes.
- Run `npm run serve` for manual browser checks.
- Check desktop and narrow layouts after visual changes.
- Keep changes small and update the repository documents when setup, architecture, or behaviour changes.
- Do not merge workshop pull requests.

## Verified Commands

- `npm test` runs the Node test suite without downloading dependencies.
- `npm run serve` serves the repository on `http://127.0.0.1:4173`.
